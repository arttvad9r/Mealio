# Mealio — Roadmap

## V1 (сделано)

- [x] Подключение: URL сервера + long-lived API-токен, нормализация URL,
      проверка соединения, инфо о пользователе/сервере.
- [x] Список рецептов (поиск/пагинация).
- [x] Карточка рецепта: ингредиенты, шаги, нутриенты, масштабирование порций.
- [x] Списки покупок: просмотр, отметка купленного, снятие отметки.
- [x] Добавление ингредиентов рецепта в список покупок.
- [x] Настройки: смена темы (light/dark/system), disconnect.
- [x] Безопасное хранение токена (Android Keystore).
- [x] Юнит-тесты, lint, debug/release APK.

## Дальше (не V1)

- [ ] Поиск и фильтры по тегам/категориям в списке рецептов.
- [ ] Оффлайн-кэш (Room) для чтения без сети.
- [ ] Планирование меню (meal planner) — неделя, слоты завтрак/обед/ужин.
- [ ] Редактирование рецептов и создание новых из приложения.
- [ ] Загрузка/удаление изображений рецепта.
- [ ] Синхронизация с Mealie в фоне (WorkManager).
- [ ] Шеринг рецепта (share intent).
- [ ] Импорт рецепта по URL.
- [ ] Мультиязычность (сейчас только ru).
- [ ] Инструментальные UI-тесты (Compose) и скриншот-тесты.

## Известные ограничения

- Нет smoke test на реальном устройстве: adb-устройств в окружении нет.
- Release-keystore генерируется локально; пароли в `keystore.properties` — не
  в репозитории. Для своих сборок используйте собственный ключ.
