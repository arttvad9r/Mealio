# Screenshots

Real Mealio screenshots live here. The README's Screenshots block renders them
from this directory; see `README.md` for the commented table markup.

Suggested set (phone screenshots, portrait):

| File                | Screen                                              |
| ------------------- | --------------------------------------------------- |
| `today.png`         | Today, with a filled day                            |
| `recipes.png`       | Recipes list                                        |
| `recipe-detail.png` | Recipe detail                                       |
| `shopping.png`      | Shopping list                                       |
| `settings.png`      | Settings (optional)                                 |
| `selector.png`      | Recipe selector sheet (optional)                    |

Keep the width around 1080px; the README scales them down. Don't commit huge
PNGs — a few hundred KB each is plenty.
