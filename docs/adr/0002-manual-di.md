# 0002 — Ручной DI вместо Hilt/Koin

Статус: Accepted, 2026-10-08

## Контекст

Приложению нужно собирать граф зависимостей: хранилище токена, настройки,
фабрика Retrofit, три репозитория. Граф маленький и линейный.

## Решение

Один ручной контейнер `data/AppContainer.kt`, создаваемый в `MealioApp.onCreate`
и доступный через `(application as MealioApp).container`. Без библиотек DI.

## Отвергнутые альтернативы

- **Hilt** — тянет KSP, кодогенерацию и процессор на весь проект ради графа из
  семи объектов; противоречит «не добавляй тяжёлые зависимости».
- **Koin** — рантайм-резолвинг и ещё одна зависимость без выигрыша на таком объёме.

## Последствия

- Провайдеры зависимостей создаются вручную; при росте графа файл придётся
  аккуратно расширять, но пока это дешевле любой библиотеки.
- Тесты подставляют зависимости напрямую, без тестовых модулей Hilt.
